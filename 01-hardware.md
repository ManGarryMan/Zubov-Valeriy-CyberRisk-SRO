# 1. Аппаратные компоненты компьютера

Для каждого компонента: что это, как работает, какие у него риски с точки зрения информационной безопасности.

## CPU (центральный процессор)

Микросхема, которая выполняет инструкции программ: арифметика, логика, управление потоком выполнения. Основные характеристики: количество ядер и потоков, тактовая частота, архитектура (x86-64, ARM), объём кэша (L1/L2/L3).

Цикл: выборка инструкции из памяти, декодирование, выполнение, запись результата. Для ускорения используются конвейер, предсказание ветвлений, спекулятивное и внеочередное исполнение.

Риски.
- Spectre / Meltdown (2018) — уязвимости, возникшие из-за спекулятивного исполнения. Процесс может косвенно прочитать данные, к которым у него нет доступа (в том числе память ядра).
- Побочные каналы (side-channel): измерение времени доступа к кэшу позволяет вытаскивать секреты, например ключи шифрования.
- Уязвимости микрокода и прошивки (Intel ME / AMD PSP) — отдельные подсистемы с высокими привилегиями.
- Защита: обновления микрокода и ОС, изоляция виртуальных машин, аппаратные расширения (Intel SGX/TDX, AMD SEV).

## RAM (оперативная память)

Быстрая энергозависимая память, где хранятся выполняемые программы и их данные. Современный стандарт — DDR5 (до него DDR4). После отключения питания содержимое теряется.

Риски.
- Cold boot attack — данные в RAM не исчезают мгновенно после выключения. Если охладить модуль и быстро снять дамп, можно достать ключи полнодискового шифрования.
- Rowhammer — частые обращения к соседним строкам памяти вызывают сбои битов в «чужих» ячейках. Это можно использовать для повышения привилегий.
- DMA-атаки — устройства с прямым доступом к памяти (Thunderbolt, PCIe) могут читать RAM в обход ОС. Защита: IOMMU (Intel VT-d / AMD-Vi).
- Секреты (пароли, ключи) лежат в памяти открытым текстом, пока программа работает; их можно достать из дампа памяти или файла подкачки.
- ECC-память исправляет одиночные ошибки и усложняет Rowhammer, но не защищает от него полностью.

## GPU (видеокарта / графический процессор)

Процессор с тысячами простых ядер, оптимизированный для параллельных вычислений. Изначально для графики, сейчас широко используется для машинного обучения и расчётов общего назначения (CUDA, OpenCL).

Риски и применение в ИБ.
- Подбор паролей: hashcat на GPU перебирает хеши в десятки-сотни раз быстрее, чем CPU. Поэтому для хранения паролей нужны медленные хеши (bcrypt, scrypt, Argon2), а не MD5/SHA-1.
- Майнинг и криптоджекинг: вредоносное ПО использует чужие GPU для добычи криптовалют.
- Утечки данных через видеопамять: после завершения процесса её содержимое может не обнуляться (исследования показывали остаточные данные).
- Большая поверхность атаки через проприетарные драйверы (работают в режиме ядра).

## HDD / SSD (накопители)

HDD — механический диск с вращающимися магнитными пластинами. Дёшево на гигабайт, медленно, чувствителен к ударам.
SSD — твердотельный накопитель на флеш-памяти (NAND), без движущихся частей. Интерфейсы: SATA и NVMe (через PCIe). Быстрее на порядки.

Риски.
- Остаточные данные. Обычное удаление файла лишь убирает запись в таблице файловой системы, сами данные остаются, пока их не перезапишут.
- SSD и безопасное стирание. Из-за wear leveling и резервных блоков перезапись файла не гарантирует уничтожение старых данных. Нужны команды ATA Secure Erase / NVMe Format, либо шифрование диска и уничтожение ключа (crypto-erase).
- Кража или потеря устройства: защита — полнодисковое шифрование (BitLocker, LUKS, FileVault).
- Выход из строя без бэкапа — это тоже риск (доступность). Правило 3-2-1 для резервных копий.
- Шифровальщики целенаправленно шифруют и уничтожают тома и теневые копии.

## Материнская плата (motherboard)

Что это. Печатная плата, соединяющая все компоненты: сокет CPU, слоты RAM, слоты PCIe, разъёмы накопителей, сетевой контроллер, чипсет, микросхема BIOS/UEFI. Через неё проходят все шины данных.

Риски.
- BIOS/UEFI-прошивка выполняется до загрузки ОС. Вредоносная прошивка (буткиты вроде LoJax, MoonBounce) переживает переустановку ОС и замену диска.
- Защита: Secure Boot, пароль на BIOS, подписанные обновления прошивки, отключение ненужной загрузки с внешних носителей.
- TPM (Trusted Platform Module) — чип для хранения ключей и проверки целостности загрузки (используется BitLocker и Windows 11).
- Физический доступ: сброс настроек BIOS перемычкой/батарейкой, подключение устройств к внутренним портам.
- Аппаратные закладки и риски цепочки поставок (supply chain).

## NIC (сетевая карта / Network Interface Controller)

Устройство, которое подключает компьютер к сети (Ethernet или Wi-Fi). Работает на канальном уровне модели OSI (L2) и частично на физическом (L1). Имеет MAC-адрес — 48-битный идентификатор.

Риски.
- Promiscuous mode — режим, в котором карта принимает все кадры, а не только адресованные ей. Используется снифферами (Wireshark, tcpdump) и злоумышленниками для перехвата трафика.
- MAC spoofing — подмена MAC-адреса для обхода фильтрации по MAC или маскировки.
- ARP spoofing / MITM — атаки на локальную сеть на канальном уровне.
- Wake-on-LAN — удалённое включение компьютера пакетом; полезная функция, но и поверхность атаки.
- Уязвимости прошивки и драйверов NIC; Intel AMT/vPro даёт удалённое управление ниже уровня ОС.
- Защита: сегментация сети (VLAN), 802.1X, port security на коммутаторах, шифрование трафика (TLS, VPN).

## Как это связано между собой

|     Компонент     |           Роль          |            Главный риск            |
|-------------------|-------------------------|------------------------------------|
|        CPU        |      исполняет код      | побочные каналы (Spectre/Meltdown) |
|        RAM        |  хранит данные в работе |     cold boot, Rowhammer, DMA      |
|        GPU        | параллельные вычисления |     ускоренный подбор паролей      |
|      HDD/SSD      |   постоянное хранение   |      остаточные данные, кража      |
| Материнская плата |      связывает всё      |        вредоносная прошивка        |
|        NIC        |      доступ к сети      |     перехват и подмена трафика     |
